# Casio Apuntes

Editor de fórmulas y apuntes para la calculadora **Casio fx-9750GIII**: escribís en la PC y exportás archivos `.py` que se copian a la calculadora por USB.

## Cómo usarlo

Abrí `index.html` con doble clic. Funciona en cualquier navegador y sin internet.

- **Modo texto (editor):** genera archivos para leer en el editor de Python de la calculadora, con las fórmulas armadas con caracteres. Hasta 150 filas por archivo; si hay más, se divide solo.
- **Modo dibujo (RUN):** genera un programa que dibuja las fórmulas en pantalla (fracciones, raíces, sumatorias, tablas, gráficos e imágenes) con menú y buscador.
- **📥 Importar texto:** pega apuntes desordenados y los ordena solo.

Los cuadernos se guardan en el navegador de cada compu (no en este repositorio).

## Pasarlo a la calculadora

1. Conectá la calculadora por USB y elegí **USB Flash** (F1).
2. Copiá los `.py` a la unidad que aparece.
3. Expulsá la unidad antes de desconectar.
4. En la calculadora: **MENU → Python**.

`prueba.py` es un programa de diagnóstico: comprueba que AC/ON se pueda usar para pasar pantallas.
